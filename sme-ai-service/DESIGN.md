# DESIGN.md — よりそいAI ホームページ

## 0. 前提

- **対象**：IT・AIに詳しくない中小企業の経営者・担当者
- **ページの役割**：ただ1つ — 「無料相談の予約」につなげること
- **既存の `index.html`**（シューティングゲーム）とは無関係の別プロジェクト。
  誤って上書きしないよう `sme-ai-service/` 配下に独立させる。

## 1. トーン & 態度

IT/AIが苦手な層への訴求なので、勢いのあるスタートアップ的トーンは逆効果。
**専門用語を使わず、隣で伴走してくれる相談役**という態度で書く。
不安（費用・セキュリティ・自分に使いこなせるか）に先回りして答える。

避けるもの：横文字の乱用（DX、ソリューション、シナジー等）、煽り文句、根拠のない実績誇示。

## 2. カラー（トークン）

初版は白ベースだったが、依頼により**背景と文字色を反転しダークベースに変更**。
「AIグラデーション紫×近黒」のようなテック企業的な配色ではなく、
引き続き**藍色（伝統的な日本の信頼色）× 落ち着いた金**を軸とし、
ベースの明暗だけを反転させている。

反転にあたり、白ベース版でトークンを兼用していた箇所
（例：`--ink`をフッター背景に流用、`--indigo`をボタン塗りとリンク文字の両方に流用）
はダークベースだと役割が破綻するため、用途別にトークンを分離した。

| トークン | 値 | 用途 |
|---|---|---|
| `--paper` | `#1B2730` | ベース背景（濃紺・ダーク） |
| `--mist` | `#141D24` | セクション交互の背景（`--paper`よりわずかに暗い帯） |
| `--ink` | `#F1F3EF` | 本文文字（純白ではなく緑みを帯びたオフホワイト） |
| `--ink-soft` | `#9CACB3` | 補助テキスト |
| `--heading` | `#D9E6EC` | 見出し・ブランドロゴ文字（本文より寒色寄りの白） |
| `--indigo` | `#7FB3D6` | リンク・アウトラインボタンの文字/枠線（ダーク背景で読める明るい藍） |
| `--indigo-fill` | `#2E6489` | ボタンの塗り背景（白文字とのコントラスト確保用） |
| `--indigo-fill-hover` | `#3B7BA1` | 塗りボタンのホバー（ダークUIらしく明るく変化） |
| `--gold` | `#B8862E` | 塗り背景（プライマリボタン・バッジ。白文字と組む） |
| `--gold-deep` | `#8F6A20` | 塗り背景のホバー（暗く変化） |
| `--gold-bright` | `#F0C877` | ページ地の上に直接乗る金（アイコン・番号・フォーカスリング・ラベル） |
| `--band` | `#0C2739` | フッター・最終CTAの専用の濃い帯（ページ全体より一段濃い藍） |
| `--line` | `#2A343C` | 区切り罫線・カード枠 |

## 3. タイポグラフィ

| 役割 | フォント | 備考 |
|---|---|---|
| 見出し（display） | Shippori Mincho | 和文明朝体。誠実さ・信頼感。太めのウェイトを控えめに使用 |
| 本文（body） | Zen Kaku Gothic New | 視認性の高いゴシック体。大きめサイズでも読みやすい |
| ラベル・キャプション | Zen Kaku Gothic New（字間を空けたMedium） | セクション見出し前の小さな導入ラベルに使用 |

- 本文基準サイズ：`19px`（一般的な16pxより大きめ、指定要件に対応）
- 行間：本文 `1.9`、見出し `1.4`
- 見出しは `clamp()` でレスポンシブスケール
- 1行の文字量は日本語で32〜36字程度に収まるようコンテンツ幅を `760px` 前後に制限

## 4. レイアウト方針

1カラムのエディトリアルな縦流れ。濃紺 (`--paper`) と さらに一段暗い帯 (`--mist`) の
セクション帯を交互に配置し、区切りに藍色の細い罫線を通す
（「道筋を示す」ラインとして繰り返し使用する構造装置）。

番号（01–04）は本当に手順である「導入の流れ」セクションにのみ使用し、
他のセクションでは装飾目的の連番を使わない。

装飾的なグラデーションヒーローや過剰なアニメーションは採用しない。
ITが苦手な層に「派手で難しそう」という印象を与えないための判断。
モーションは `prefers-reduced-motion` を尊重し、スクロール時のフェード程度に留める。

## 5. ページ構成（セクション単位で実装）

1. ヘッダー / ナビゲーション（固定・CTAボタン）
2. ヒーロー（訴求コピー＋一次/二次CTA＋安心材料）
3. 課題共感（よくある悩み4つ）
4. できること（サービス内容4つ）
5. 選ばれる理由（差別化ポイント4つ）
6. 導入の流れ（4ステップ・唯一の連番使用箇所）
7. 料金プラン（3プラン）
8. お客様の声（3件・※サンプル明記）
9. よくある質問（4問）
10. 最終CTA
11. フッター

## 6. 実装メモ

- 単一の `index.html`（`<style>` 埋め込み）として自己完結させる
- Google Fonts は `<link>` 読み込み（通常のWebサイトのためCDN利用可）
- ライト/ダークの配慮：依頼によりダークベース（背景と文字色を反転）に変更済み。
  `prefers-color-scheme` によるOS追従は行わず、固定のダークテーマとして運用する
  （意図的なシングルテーマ運用）
- レスポンシブ：480px / 768px / 1080px 付近でブレークポイント
- アクセシビリティ：フォーカスリング可視化、コントラスト比確保、`alt`不要な装飾要素は`aria-hidden`
