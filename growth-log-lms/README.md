# 成長ログ(Growth Log)

社員一人ひとりの **学びの記録と振り返り** を中心に据えた、企業向け LMS の画面プロトタイプです。
一般的な LMS の「受講管理」ではなく、研修のあとに AI「ナビ」が対話で振り返りを促し、
その記録を数年単位で貯めて、本人が自分の成長を自分で確かめられることを目的にしています。

バックエンド・実際の AI 呼び出し・実際の録画処理は含みません。
モックデータとダミーの動きで、画面遷移と体験を確認するためのものです。

## 起動方法

Node.js 20 以上が必要です。

```bash
cd growth-log-lms
npm install
npm run dev
```

表示された URL(既定は http://localhost:5173)をブラウザで開きます。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動する |
| `npm run build` | 型チェックと本番ビルド(`dist/`)を行う |
| `npm run preview` | ビルド結果を確認する |
| `npm run typecheck` | 型チェックのみ行う |

### カメラについて

振り返りセッションでは `getUserMedia` で **カメラのプレビューだけ** を行います。映像は保存も送信もしません。
カメラを許可しなかった場合や、使えない環境でも体験は止まらず、文章だけで最後まで進められます。

## 画面一覧

| # | 画面 | パス | 内容 |
| --- | --- | --- | --- |
| 1 | ホーム(ダッシュボード) | `/` | 振り返り待ちの通知、直近の記録、行動目標の積み重ね、ナビの今週のひとこと |
| 2 | 研修・学びの登録 | `/register` | 種類・名称・日付・主催・メモ。登録してそのまま振り返りに進める |
| 3a | セッション開始前 | `/session/:recordId` | カメラ/マイク確認、保存の同意、深呼吸の間 |
| 3b | AI振り返りセッション | `/session/:recordId/run` | 3つの質問のステップ UI、カメラ映像、録画状態、リアルタイム字幕、深掘り質問 |
| 4 | セッション完了・サマリー | `/session/:recordId/summary` | ナビが整えた3項目の確認・修正、行動目標と期限の確定 |
| 5 | 成長タイムライン | `/timeline` | 月ごとの時系列表示、テーマの広がり、種類/テーマ/期間/キーワードでの絞り込み |
| 6 | 記録詳細 | `/records/:recordId` | 映像再生、文字起こし(該当箇所へジャンプ)、3つの答え、行動目標、あとからのメモ、公開範囲 |
| 7 | 行動目標トラッカー | `/goals` | 目標の一覧と状態(未着手/実行中/達成/見直し)、進捗の書き足し、ナビからの声かけ |
| 8 | 成長レビュー(自己評価) | `/review` | 期間の選択、過去の自分と今の自分の比較、実感の言葉による自己評価 |
| 9 | AIアドバイス | `/advice` | 強み/伸びしろ/次に学ぶとよいこと、**根拠となった記録へのリンク**、役に立った/違うと思う |
| 10 | プライバシー・データ設定 | `/settings` | 保存期間、公開範囲、共有中の記録、書き出し、削除 |

`/session/*` の3画面だけはサイドナビを出さない「集中モード」で表示します。
録画中に他の画面へ迷い込まないようにし、中断の操作は常に画面上に置いています。

### 試してみるとよい流れ

1. ホームの「交渉力ワークショップ」で **振り返りを始める** を押す
2. 同意にチェックして **はじめる**(深呼吸の間が入ります)
3. 1問目に短く答えて次へ進むと、ナビが **1度だけ深掘り** します
4. **話して答える** を押すと、音声認識の代わりに下書きが少しずつ入ります
5. 3問答えるとサマリー画面になり、文面を直して行動目標を確定できます
6. 途中で **中断する / あとで続ける** を押すと下書きとして保存され、ホームに「続きから」で戻ります
   (「社内勉強会『チームの心理的安全性』」が、その途中状態のモックです)

## 設計の方針

- **急かさない**:未対応は赤ではなく琥珀色で、「振り返りませんか」という誘いとして出す。
  進み具合は3つの点だけで示し、残り時間やパーセンテージは出さない。
- **評価しない**:点数・偏差値・ランキング・達成率を出さない。
  成長は「時間の流れ」「テーマの広がり」「行動の積み重ね」として見せる。自己評価も数値ではなく言葉で選ぶ。
- **いつでも降りられる**:録画画面のどこにも閉じられない状態を作らない。中断は破棄ではなく保存。
- **AI の透明性**:アドバイスには必ず根拠となった記録へのリンクを添える。
- **ナビの表現**:キャラクター化せず、同心円の印だけで表す。一人称は使わず、敬語は控えめにする。

### アクセシビリティ

- 文字色と背景の組み合わせは WCAG AA(4.5:1)以上。録画の赤も 4.8:1 を確保しています。
- すべての操作をキーボードで行えます。セッション画面では `Space` で一時停止、`→` で次の質問、`Esc` で中断の確認。
- フォーカスリングを全要素で可視にしています。字幕は常時表示で、大きさを3段階から選べます。
- 本文の最小サイズは 15px、行間は 1.75。`prefers-reduced-motion` を尊重します。

## ディレクトリ構成

```
src/
├── design/tokens.ts     デザイントークン(色・余白・文字サイズ・角丸・影)の唯一の出どころ
├── data/                型定義・モックデータ・3つの質問の文面
├── store/AppStore.tsx   記録・目標・自己評価・設定の状態(Context + useReducer)
├── lib/                 日付整形、ラベル、ナビのふるまい、カメラのフック
├── components/
│   ├── ui/              Button, Card, Tag, Field, Dialog, StepBar, CameraStage など
│   ├── navi/            ナビの印と吹き出し
│   ├── viz/             テーマの広がり・行動の積み重ね
│   └── layout/          通常画面の枠(サイドナビ/下部ナビ)
└── features/            画面ごとの実装
```

`tailwind.config.ts` は `src/design/tokens.ts` を読み込んでテーマを組み立てます。
色や余白を変えるときは、トークンのファイルだけを編集してください。

### モックデータ

`src/data/mock.ts` に、2025年9月〜2026年9月の約1年分を用意しています。

- 学びの記録 17件(外部研修7・社内研修5・勉強会5)。うち15件は振り返り済み、1件が振り返り待ち、1件が途中まで
- 行動目標 22件(未着手4・実行中5・達成11・見直し2)、進捗メモ付き
- テーマのタグ 25種類、自己評価 1件、AIアドバイス 3件(それぞれ根拠の記録付き)

プロトタイプ内の「今日」は `TODAY`(2026-09-20)で固定しています。

## 置いている仮定

- 認証はスコープ外。「田中 悠介(営業推進部・5年目)」でログイン済みという前提です。
- AI との対話は音声+テキスト字幕のハイブリッド。文章だけでも最後まで進められます。
- 映像は本人の同意のもとで保存し、初期設定では本人のみ閲覧可能です。
- 上長・人事向けの画面は作っていません。共有は本人側の操作(公開範囲の変更)としてのみ実装しています。
- ナビの深掘り・サマリー整形・テーマ付けは、`src/lib/navi.ts` のルールで再現しています。
  実際の LLM に差し替えるときは、このファイルの関数を置き換えてください。
- 状態はメモリ上にのみ保持します。再読み込みするとモックデータの初期状態に戻ります。
